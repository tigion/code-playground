# Hangman

A simple game written in Lua. The goal is to guess a word.

## How to run

1. Navigate to the _hangman/_ folder with `cd hangman/`.
2. Run it with `lua main.lua`.
3. Follow the instructions.

## How to play

```text
Welcome to Hangman!

Find a word with 5 letters.

_ _ _ _ _

10/10 lives
Used:
Which letter is in the word? a
> Correct :)

_ _ A _ _

10/10 lives
Used: A
Which letter is in the word? l
> Wrong, you lose a life :(

_ _ A _ _

9/10 lives
Used: A,L
Which letter is in the word?

...
```
