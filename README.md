# Code Playground

This is a collection of small, beginner-friendly coding projects and tutorials.

The code playgrounds are organised by programming language, making it easy to
explore and learn new languages. Each playground contains annotated code with
explanations for beginners, as well as instructions on how to create and run the
project.

| Difficulty      | Languages                                                                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 📘 Starter      | [Scratch](#-scratch)                                                                                                             |
| 📗 Beginner     | [Lua](#-lua), [PHP](#-php), [Python](#-python), [Ruby](#-ruby)                                                                   |
| 📙 Intermediate | [Bash](#-bash), [C#](#-c-2), [Go](#-go), [Java](#-java), [JavaScript](#-javascript)/[TypeScript](#-typescript), [Swift](#-swift) |
| 📕 Advanced     | [C](#-c), [C++](#-c-1), [Rust](#-rust), [Zig](#-zig)                                                                             |

> [!TIP]
>
> It's usually best to start with [Python](#-python) and then explore other
> languages. [Scratch](#-scratch) is more suitable for children and absolute
> beginners.
